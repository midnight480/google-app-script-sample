# Gmail to Slack with Filtering

Gmail に届いたメールのうち、**特定の送信元（From）から届いたもの**だけを選び、本文から**必要な項目だけを抜き出して Slack に通知**する Google Apps Script です。通知した内容は**スプレッドシートにも記録**されるので、あとから集計できます。

たとえば「イベント申し込みの通知メールから、氏名・都道府県・年齢だけを Slack に流し、シートで都道府県別の人数を数える」といった使い方ができます。

**抜き出す項目は、プログラムを書き換えずに設定画面から変えられます。**

## 🎯 できること

- 送信元（From）でメールを絞り込む。宛先（To）でも絞り込める（任意）
- 本文から「会社名」「氏名」「所属部署」「連絡先」「都道府県」など、**好きな項目を抜き出す**
- Slack に見やすい形式で通知する（件名・抜き出した項目・受信日時・Gmail へのリンク）
- 通知した内容をスプレッドシートに1行ずつ記録する（項目ごとに列が分かれるので集計しやすい）
- 5分ごとに自動でチェックする

## 🏗 動きのイメージ

```
Gmail                      Google Apps Script（5分ごと）             Slack / スプレッドシート
  │                               │                                     │
  │  新しいメール                  │ 1. From / To で絞り込む              │
  ├──────────────────────────────>│ 2. 本文から項目を抜き出す            │
  │                               │ 3. Slack に通知する  ───────────────>│ #通知先チャンネル
  │                               │ 4. シートに記録する  ───────────────>│ 「通知履歴」シート
```

### Slack の通知例

```
┌──────────────────────────────────────────┐
│ ［入場チケット］イベントで新規申し込みがありました │  ← 件名
│                                          │
│ 氏名           都道府県                   │  ← 抜き出した項目
│ 山田 太郎      東京都                     │
│ 年齢           コメント                   │
│ 20歳以上       （なし）                   │  ← 本文になかった項目
│                                          │
│ 受信日時: 2025/10/11 19:30:33             │
│ [Gmailで開く]                             │
└──────────────────────────────────────────┘
```

### スプレッドシートの記録例（シート名: 通知履歴）

| 記録日時 | 受信日時 | 件名 | From | To | Slack送信 | Gmailリンク | メールID | 氏名 | 都道府県 | 年齢 | コメント |
|---|---|---|---|---|---|---|---|---|---|---|---|
| 2025/10/11 19:31 | 2025/10/11 19:30 | ［入場チケット］… | info@example.com | me@example.com | 成功 | https://mail.google.com/… | 19a1b… | 山田 太郎 | 東京都 | 20歳以上 | （なし） |

## ⚙️ セットアップ（最初の1回だけ）

> 💡 AI エージェント（Claude Code など）を使える場合は、このフォルダで「セットアップして」と頼むと
> [`.claude/skills/setup-gmail-to-slack`](.claude/skills/setup-gmail-to-slack/SKILL.md) の手順で案内してくれます。

### 手順1. Slack アプリを作る

1. https://api.slack.com/apps を開き、**Create New App** → **From scratch** を選ぶ
2. アプリ名（例: `メール通知`）と、通知したいワークスペースを選んで作成
3. 左メニュー **OAuth & Permissions** → **Bot Token Scopes** に `chat:write` を追加
4. ページ上部の **Install to Workspace** を押して許可する
5. 表示された **Bot User OAuth Token**（`xoxb-` で始まる文字列）をコピーしておく
6. Slack で通知先のチャンネルを開き、メッセージ欄に `/invite @メール通知`（作ったアプリ名）と入力してアプリを招待する
7. チャンネル名をクリック → いちばん下の **チャンネルID**（`C` で始まる文字列）をコピーしておく

### 手順2. GAS プロジェクトを作る

ターミナルで次を実行します（[clasp](https://github.com/google/clasp) が必要です）。

```bash
cd gmail-to-slack-with-filtering

# Google にログイン（初回のみ）
clasp login

# プロジェクトを作成
clasp create-script --type standalone --title "gmail-to-slack-with-filtering"

# ⚠️ create-script で appsscript.json が初期状態に上書きされるため、元に戻す
cp appsscript.json.example appsscript.json

# コードをアップロード
clasp push

# ブラウザで開く
clasp open-script
```

> すでにプロジェクトがある場合は、`.clasp.json.example` を `.clasp.json` にコピーし、`scriptId` を書き換えてから `clasp push` してください。

### 手順3. 設定（スクリプトプロパティ）を入れる

1. GAS エディタの上部で関数 `initializeConfig` を選んで **実行**
   - 初回は「承認が必要です」と出るので、自分のアカウントを選んで許可します
   - 「このアプリは Google で確認されていません」と出たら **詳細** → **（プロジェクト名）に移動** を押します
2. 左メニューの ⚙️ **プロジェクトの設定** → 下のほうの **スクリプト プロパティ** を開く
3. 仮の値が入った項目が並んでいるので、次の表のとおり書き換える

| プロパティ | 必須 | 入れる値 | 例 |
|---|---|---|---|
| `FROM_ADDRESSES` | ✅ | 送信元のメールアドレス。複数ならカンマ区切り | `info@example.com` |
| `TO_ADDRESSES` | — | 宛先のメールアドレス（自分やメーリングリスト）。複数ならカンマ区切り。**空にすると From だけで判定** | `team@example.com` |
| `EXTRACT_FIELDS` | ✅ | 抜き出す項目（書き方は下の「抜き出す項目の設定」） | `[{"name":"都道府県","label":"都道府県"}]` |
| `SLACK_BOT_TOKEN` | ✅ | 手順1でコピーした `xoxb-` で始まるトークン | `xoxb-...` |
| `SLACK_CHANNEL_ID` | ✅ | 手順1でコピーしたチャンネルID | `C0123456789` |
| `SPREADSHEET_ID` | — | 記録先のスプレッドシートID。**空なら自動で作られます** | — |

> `TO_ADDRESSES` は、メールの **To 欄**に書かれたアドレスで判定します（Cc は見ません）。

### 手順4. 動作を確認する

GAS エディタで、次の関数を順に実行します。結果は画面下の **実行ログ** に出ます。

| 順番 | 関数 | 確認できること |
|---|---|---|
| 1 | `checkConfiguration` | 設定に間違いがないか。「設定に問題はありません」と出れば OK |
| 2 | `previewExtraction` | 条件に合う最新のメール（30日以内）で、項目が正しく抜き出せるか。**Slack には送りません** |
| 3 | `testSlackNotification` | Slack にテスト通知が届くか。スプレッドシートにもテスト行が記録されます |
| 4 | `setupSpreadsheet` | 記録用スプレッドシートの URL を表示 |

### 手順5. 自動実行を始める

`createTrigger` を実行すると、5分ごとに自動でチェックが始まります。

- **初回の自動実行では通知されません。** その時点を起点にして、**それ以降に届いたメールから通知**します（過去のメールが一気に流れるのを防ぐため）
- 止めたいときは `deleteTriggers` を実行します

## ✏️ 抜き出す項目の設定（EXTRACT_FIELDS）

> 💡 AI エージェントを使える場合は、サンプルのメール（.eml ファイルや本文のコピー）を渡して
> 「この項目を抜き出したい」と頼むと、[`.claude/skills/customize-extract-fields`](.claude/skills/customize-extract-fields/SKILL.md)
> の手順で設定値を作ってくれます。

### 書き方

```json
[
  {"name": "Slackとシートに表示する名前", "label": "メール本文に書かれている項目名"}
]
```

- `name`: Slack とスプレッドシートの列に表示される名前。自由に付けてかまいません（重複は不可）
- `label`: メール本文に書かれている項目名。**一字一句同じ**にします（前後の空白や改行の違いは無視されます）

項目を増やすときは `{ }` をカンマでつなぎます。最後の `}` の後ろにはカンマを付けません。

### 対応しているメールの形式

**形式A: 「項目名: 値」が1行にある**

```
会社名: サンプル株式会社
お名前：山田 太郎
所属部署：営業部
電話番号: 03-0000-0000
```

```json
[
  {"name": "会社名", "label": "会社名"},
  {"name": "氏名", "label": "お名前"},
  {"name": "所属部署", "label": "所属部署"},
  {"name": "連絡先", "label": "電話番号"}
]
```

**形式B: 項目名と値が空行で区切られている**（Doorkeeper の申し込み通知など）

```
都道府県

東京都

年齢

20歳以上
```

```json
[
  {"name": "都道府県", "label": "都道府県"},
  {"name": "年齢", "label": "年齢"}
]
```

形式A と形式B は自動で見分けるので、どちらの形式でも同じ書き方で設定できます。

### 項目名が長い・メールの種類で項目名が違う場合

項目名は**全文をそのまま**書きます。たとえば次のような項目名なら、括弧の中まで含めます。

```
氏名 漢字（ニックネーム不可。保険加入のため本名を記入ください）
```

チケットの種類などで同じ内容の項目名が違う場合は、**別々の項目として登録**します。

```json
[
  {"name": "氏名", "label": "氏名 漢字（ニックネーム不可。保険加入のため本名を記入ください）"},
  {"name": "氏名（同伴者）", "label": "18歳以下同伴者の漢字氏名（ニックネーム不可。保険加入のため本名を記入ください）"}
]
```

メールに含まれない側は「（なし）」と表示されます。

### 項目名の見つけ方

1. Gmail で対象のメールを開く
2. 抜き出したい値の**すぐ上（または左）にある項目名**をコピーする
3. `EXTRACT_FIELDS` の `label` に貼り付ける
4. `previewExtraction` を実行し、✅ が付くか確認する（❌ なら項目名が一致していません）

### うまく抜き出せないとき

| 症状 | 原因と対処 |
|---|---|
| ❌（なし）になる | `label` がメールの項目名と一字一句同じか確認。全角・半角、括弧、スペースの違いに注意 |
| 別の項目名が値として表示される | 形式B で、その項目が未回答のときに起こります。**次に続く項目名も `EXTRACT_FIELDS` に登録**すると「（なし）」と判定されます（下の「制約」参照） |
| `EXTRACT_FIELDS の JSON が読み取れません` と出る | カンマの付け忘れ・付けすぎ、`"` の閉じ忘れがないか確認 |

## 📊 スプレッドシートでの集計

- 記録先は `SPREADSHEET_ID` のスプレッドシートの **「通知履歴」** シートです。`SPREADSHEET_ID` が空なら、最初の記録時に自動で作られ、ID が保存されます
- 抜き出した項目は**1項目1列**になります。たとえば「都道府県別の申込数」は、ピボットテーブルで「行: 都道府県 / 値: 件名の COUNTA」にすれば集計できます
- `EXTRACT_FIELDS` に項目を追加すると、**右端に列が自動で追加**されます。使わなくなった列は消さずに残します（過去の記録を守るため）
- Slack 送信に失敗したメールも「Slack送信: 失敗」として記録されます。次回の再試行で成功すると、同じ行が「成功」に更新されます
- 見出し行（1行目）の名前は変更しないでください。列の対応づけに使っています（列の順番の入れ替えは可能です）

> ⚠️ スプレッドシートには氏名や連絡先などの**個人情報が残ります**。共有範囲に注意してください。

## 🔧 関数一覧

| 関数 | 用途 |
|---|---|
| `main` | メイン処理（トリガーから5分ごとに実行） |
| `initializeConfig` | スクリプトプロパティに仮の値を入れる（未設定の項目だけ） |
| `checkConfiguration` | 設定の確認 |
| `previewExtraction` | 最新のメールで抽出結果を確認（Slack には送らない） |
| `testExtractFields` | 抽出ロジックのテスト（ダミーの本文を使用） |
| `testSlackNotification` | Slack へのテスト送信と、シートへのテスト記録 |
| `setupSpreadsheet` | 記録用スプレッドシートを用意して URL を表示 |
| `createTrigger` | 5分ごとの自動実行を開始 |
| `deleteTriggers` | 自動実行を停止 |
| `resetLastProcessedAt` | 処理済みの位置をリセット（次回の実行が初回扱いになる） |

## 🗂 自動で使われるスクリプトプロパティ

次の項目はスクリプトが自動で書き込みます。通常は触る必要はありません。

| プロパティ | 内容 |
|---|---|
| `LAST_PROCESSED_AT` | 最後に処理したメールの受信日時（ミリ秒） |
| `LAST_PROCESSED_IDS` | その時刻に処理したメールのID（同じ時刻のメールを二重に通知しないため） |
| `SPREADSHEET_ID` | 自動作成したスプレッドシートのID |

## ⚠️ 制約

- 本文は**テキスト形式**で読みます。HTML だけのメールは、Gmail がテキストに変換した内容に依存します
- 形式B で項目が未回答のとき、次の段落が **`EXTRACT_FIELDS` に登録していない項目名** だと、それを値として表示してしまいます。気になる場合は、その項目名も登録してください
- 「最後に処理した受信日時」より古い日時のメール（配送が大きく遅れたメールなど）は通知されません
- 1回の実行で処理するのは最大20通です。残りは次回（5分後）に処理されます
- Slack 送信に失敗したメールがあると、そのメール以降は次回に再試行します。失敗が続く場合は `checkConfiguration` と実行ログを確認してください

## 🩺 トラブルシューティング

| 症状 | 確認すること |
|---|---|
| 通知が来ない | `createTrigger` を実行したか / 初回の自動実行は通知しない仕様 / `checkConfiguration` でエラーがないか |
| `not_in_channel` エラー | Slack のチャンネルにアプリを招待したか（手順1-6） |
| `invalid_auth` エラー | `SLACK_BOT_TOKEN` が正しいか（`xoxb-` で始まるか） |
| `channel_not_found` エラー | `SLACK_CHANNEL_ID` がチャンネル名ではなく ID（`C...`）になっているか |
| To で絞り込むと通知されない | メールの **To 欄** に `TO_ADDRESSES` のアドレスが入っているか（Cc / Bcc は対象外） |
| 過去のメールも通知したい | `LAST_PROCESSED_AT` を手で古い日時（ミリ秒）に書き換える。例: 2025/10/01 0:00 なら `1759244400000` |
